# AED 2026

Repositório com atividades práticas de **Algoritmos e Estruturas de Dados (AED)** desenvolvidas em 2026.

## Objetivo

Organizar exercícios, laboratórios e atividades em Python para estudo e prática de lógica, estruturas básicas, repetição, funções e resolução de problemas.

## Organização do conteúdo

Com base na estrutura atual do repositório:

- `./.python codes/`  
  Conjunto principal de exercícios, separado por laboratórios (`lab1`, `lab2`, ..., `lab10`), além de pastas como `labval1`, `labval2`, `testes-e-codsextras` e `trabalho de aed`.
- `./atividade alp/`  
  Atividade com `main.py` e `funcoes.py`, com execução interativa no terminal.
- `./.vscode/`  
  Configurações locais do editor.

## Requisitos

- Python 3 instalado no ambiente.
- Terminal para executar scripts `.py`.

## Como executar

Como os arquivos são, em geral, scripts independentes, execute diretamente o arquivo desejado:

```bash
python3 "CAMINHO/DO/ARQUIVO.py"
```

Exemplo:

```bash
python3 "/home/runner/work/AED-2026/AED-2026/atividade alp/main.py"
```

## Observações

- Não foi identificado, nesta estrutura, um único ponto de entrada para todo o projeto; o uso é por arquivo/atividade.
- Há scripts interativos que solicitam entrada via teclado.
