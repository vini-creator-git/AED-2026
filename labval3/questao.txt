Exercícios sobre Vetores.

1) Entrada de Dados : Faça um vetor com 10 notas de alunos de uma turma. Faça outro vetor com 10 nomes de alunos. Utilize o comando "input". Use um programa principal com funções externas (import from);

2) Média das notas: Use uma função externas para calcular a média das notas no vetor;

3) Alunos acima da Média: Use uma função externa para calcular quantos alunos estão acima ou igual a média;

4) Separação de notas: Use uma função externa para separar as notas das posições pares e impares. Pesquise a utilização do método "append";

5) Estatística com vetor de notas: a) Qual o percentual de alunos aprovados (nota >=7,0);  b) Qual o percentual de alunos em recuperação (nota >= 5) e Qual percentual de reprovados;

6) Notas de alunos: recuperar a maior nota e o aluno que a recebeu;

7) Vetor de conceitos: Transformar o vetor de notas para um vetor de conceitos. (>= 9,0 -> A);  (>=7, 0 a 8,9 -> B); (>=5 a 6,9 -> C), (<5 -> D).
